Вход

Правки сохраняются прямо в репозиторий сайта, поэтому «паролем» служит ключ доступа GitHub (токен). Без него страница ничего не изменит, даже если её кто-то откроет.

Где взять ключ
  1. Откройте github.com/settings/personal-access-tokens/new.
  2. Название любое, срок действия, например, 90 дней.
  3. Repository access: Only select repositories, выберите foy4ik.github.io.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Нажмите Generate token и вставьте его сюда. Никому его не передавайте: отозвать можно там же в любой момент.

Сами файлы картинок нужно положить в папку images/ репозитория (это делаю я или вы через git), здесь указывается только путь.

Тексты и скриншоты шаблонов лежат в коде сайта, а здесь меняется то, что бывает разным: цена, срок, ссылка на демо и видимость. Пока цена не указана, на сайте написано «Цена - по запросу».

Отзывы показываются на сайте только если они здесь есть. Добавляйте только настоящие: с разрешения автора.
